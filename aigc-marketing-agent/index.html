01 — PRODUCT LOOP / 问题 · 输入 · 输出

先让人看懂产品，再展开它如何工作。

品牌策划往往需要同时处理定位、受众、平台和营销目标。这个原型把依赖个人经验的前期判断，整理成可复用、可检查的输入与输出结构。

01

痛点：依赖经验

策划过程容易依赖个人经验，选题分类与判断标准不够统一。

02

痛点：难以落地

品牌信息、受众洞察与选题之间需要建立更清晰的对应关系。

03

目标：方法显性化

用结构化输入、Prompt 与 Agent 流程，生成便于阅读和人工评估的内容策略建议。

03 — OUTPUT PROOF / 品牌分析 · 五类选题 · Top 3

从品牌定位，到可直接落地的选题。

以下展示元气森林测试场景的部分返回结果。一次运行生成 10 个选题，覆盖五类方向；每个选题按标题、切入角度、目标受众、吸引点与推荐理由组织，并提供 Top 3 推荐。页面仅展示部分选题标题与推荐节选，完整输出以测试记录为准。

定位

核心价值

为追求健康的年轻人提供「好喝无负担」的饮品，打破「好喝不健康、健康不好喝」的刻板印象。

卖点

差异化卖点

核心卖点「0糖0脂0卡」，兼顾气泡水爽口与健康属性，多口味适配多元场景。

基调

内容基调

闺蜜式分享，活泼接地气、有共鸣感，兼顾实用与种草，贴合小红书年轻女性偏好。

TOP 3 · PRIORITY PICK

01
晒出你的元气森林专属喝法！被翻牌送全年畅饮权互动型

互动机制与「提升互动率」目标相关，但全年畅饮等福利需要品牌确认资源与活动规则；未经人工核验，不宜直接作为可执行方案。

02
减脂期嘴馋想喝甜的别忍！这瓶快乐水我敢按箱囤痛点型

精准戳中目标用户核心痛点，共鸣感强，易获高赞藏；制作成本极低，实拍加文字即可落地，吸引控糖减脂的精准用户。

03
特种兵式旅游必备饮品！0糖0卡喝一路都没负担热点型

借势出游场景，产品植入相对自然；但该方向需要先核验热点时效与平台趋势，当前 Agent 未接入实时热点检索，不能据此判断实际流量表现。

人工审核提示：模型生成的福利活动、产品功效表述与热点判断均需结合品牌真实政策、产品资料及平台实时趋势核验；Top 3 是模型给出的建议排序，不代表经过量化实验验证的效果排名。
