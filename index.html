01 / INSIGHT

一个允许自己
暂停的理由。

围绕下班后、独处、雨天与深夜，以四种情绪建立饮品系列，让品牌成为日常的轻量陪伴。

个人概念探索 · 以情绪场景作为设计假设

02 / BRAND + PRODUCT SYSTEM

情绪 × 天气 × 饮品

RELAX、WARM、JOY、QUIET 四个系列共享同一品牌语言，又以风味、色彩和场景区分情绪。

03 / CAMPAIGN

让情绪，
有自己的画面。

一杯清爽，一点甜。以两种色彩与场景，表达放松和小确幸。

04 / BRAND FILM

风、光与气泡。WIND / LIGHT / LIQUID

让风、光、气泡与液体共同承担叙事，把品牌情绪从静态视觉延展到约 20 秒的动态体验。

05 / PROCESS + FULL DECK

规则约束生成，
判断保证一致。

独立完成概念、生成筛选与精修，重点检查产品辨识度、材质和系列一致性。

  1. 定义明确产品线、情绪与场景
  2. 生成约束光线、材质与镜头语言
  3. 筛选与精修检查构图、标志与产品一致性
  4. 输出延展至海报、影像与社媒视觉

01 / REFERENCE

确立氛围与材质

从夕阳、自然光、透明材质、液体质感与生活方式场景出发，以产品作为画面主体。

02 / GENERATION

识别生成中的偏差

比较装饰过多、主体不突出、产品形态不稳定、材质不真实与品牌辨识度不足的方案。

03 / REFINEMENT

统一产品与系列

减少装饰干扰，强化前中后景；建立独立色彩与氛围，检查标志位置、杯型、材质和光影。

04 / FINAL

从探索收束到定稿

将筛选结果整合成四杯主视觉。过程图底部保留早期场景探索，展示调整方向，并与最终方案区分。
