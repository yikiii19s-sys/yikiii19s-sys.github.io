PROJECT 06 / AI TRAVEL CREATIVE — IMMERSIVE 3D EXPERIENCE

WAYFINDER48H · AI 旅行创意与沉浸式 3D 交互项目

独立策划、创意设计与开发 · Vibe Coding 个人项目

体验 3D 交互原型 ↗ 旋转 · 缩放 · 拖动时间

01 — BUSINESS QUESTION & USER INSIGHT / 命题与洞察

48 小时旅行，如何从灵感转化为决策与传播内容？

围绕短途旅行场景拆解业务命题，梳理旅行者在信息筛选、路线取舍、内容收藏和出行决策中的核心痛点，并将分散的旅行信息组织为可理解、可选择、可分享的体验路径。

信息筛选

从大量目的地内容中找到真正相关的信息。

路线取舍

在有限时间内平衡距离、体验与节奏。

内容收藏

让灵感不只停留在分散的截图和链接。

出行决策

缩短从“想去”到“可以出发”的路径。

02 — CREATIVE SYSTEM & MARKETING / 创意与传播

把旅行内容组织成一座可以探索的微缩世界。

独立完成从洞察、创意策略、视觉概念到交互落地的全流程设计。以可自由旋转、缩放和探索的微缩旅行世界为核心，通过五个空间入口呈现洞察、路线、AI 创意、营销传播与项目复盘。

主视觉

用统一的空间语言建立项目识别。

社交内容

适配快速浏览、收藏与分享场景。

短视频叙事

将路线与情绪转化为动态内容。

分享物料

根据渠道与信息密度调整表达。

03 — AI WORKFLOW / AI 创意工作流

让生成式 AI 参与研究、发散与生产，而不是替代判断。

运用 LLM 与生成式 AI 辅助用户研究归纳、创意发散、文案组织、视觉方向探索和内容生产，再通过人工筛选与迭代保障品牌一致性、视觉完成度和业务表达准确性。

业务洞察

归纳用户问题与内容机会。

创意策略

建立概念、结构与视觉方向。

AI 生产

生成并筛选文案与视觉内容。

验证复盘

检查一致性并沉淀 Prompt 与规则。

04 — VIBE CODING / 3D 交互实现

把创意策略做成可以亲自探索的运行原型。

基于 React、React Three Fiber、Three.js 与 Web Audio API 完成可运行原型，落地 GLB 模型、实时昼夜光影、相机控制、射线交互、场景状态、声音反馈及响应式适配。

3D 世界

GLB 模型、微缩岛屿与五个空间入口。

光影与相机

实时昼夜变化、旋转、缩放与探索。

交互与状态

射线检测、点击反馈和场景状态管理。

声音与适配

Web Audio 反馈及响应式设备体验。

LIVE 3D SYSTEM拖动时间 · 实时昼夜与环境光影

同一场景根据世界时间实时切换天空、环境光、材质明暗与氛围色；用户可通过右键拖动时间，并以左键旋转、滚轮缩放探索微缩世界。

PROJECT 07 / INTERACTIVE — EXPERIENCE PROTOTYPE

SSD UNIT三星堆未来祭典 · 可运行虚拟舞台

让古老文明的角色，走进一场可以亲手唤醒的未来祭典。

进入祭典体验 ↗ 角色唤醒 · 灯光切换 · 五频合奏

01 — CONCEPT / 项目定位

从观看角色，到参与演出。

从三星堆青铜面具、神树、青铜鸟、玉戈与太阳轮中提取角色线索，用五位表演者、灯光和声音，把静态 IP 设定延伸成一场可运行的互动演出。个人概念探索 · AI 辅助视觉生成与代码实现。

02 — EXPERIENCE FLOW / 体验流程

五种频率，连接古蜀与未来。

五位角色分别承担引导、采样、解码、破界与融合的叙事任务。色彩与灯光让角色切换成为演出的章节变化；神树逐层点亮与太阳轮启动，构成最后的共同高潮。

01

进入

点击进入解锁声音，拖动舞台改变观看角度，滚轮缩放镜头。

02

唤醒

点击人物或下方角色图腾，切换对应章节、灯光与镜头，也可用键盘 1–5。

03

合奏

五位角色全部唤醒后自动合奏；也可点击“开启合奏”直接观看约 12 秒的演出。

04

导演模式

可选打开 Director Mode，调整灯光、镜头、能量与氛围。

03 — INTERFACE / 界面与舞台

先把舞台交给观众。

默认界面保留轻量提示，让观众先看见舞台。当前角色采用 2.5D 影像装置（人物图像置于三维舞台中），重点展示 IP 叙事、视觉氛围和交互体验；这是概念原型，尚非完整三维角色演出产品。

金 / 引导

以金色青铜面具，建立舞台的第一印象。

森 / 采样

以神树为线索，采集古蜀世界的片段。

爻 / 解码

以青铜鸟为媒介，解码符号与纹样。

玉 / 破界

以玉戈为切口，打破时间的边界。

阳 / 融合

以太阳轮为高潮，完成古蜀与未来的合奏。

进入祭典体验 ↗ 约 1 分钟即可体验主要流程 · 进入后可关闭声音

原型边界：当前角色采用 2.5D 影像装置，重点验证 IP 叙事、舞台氛围与交互流程；尚未接入完整三维角色和正式用户研究。

04 — CASE STUDY / 体验与运营方案

让一场祭典，成为一次能完成的体验。

在现有五频角色与互动舞台的基础上，梳理用户从认识角色、完成首次互动到探索合奏的路径。案例研究进一步提出内容栏目、AIGC 审核流程、事件口径与小规模验证计划。

角色内容首次互动五频探索合奏完成记录与回访

项目仍为概念原型：进度记录、完成卡与回访机制是后续方案，尚未接入舞台；正式用户研究、运营实验与增长数据尚未取得。

PROJECT 01 / ART DIRECTION · SELECTED VISUALS · AIGC

VISUAL PLAYGROUND
视觉实验

五组独立的视觉探索，分别研究千禧怀旧、城市中的超现实暂停、声音的字体表达、材质与身体，以及从日常通勤延伸出的想象场景。这里展示的是图像语言与系列控制，不对应虚构的品牌或商业委托。

01 / Y2K CALLING

千禧来电

接收一通来自千禧年的来电。透明设备、金属字体与时装影像共同构成未来怀旧的三帧叙事。

CH 01 / INCOMING CALL
Y2K BROADCAST / 3 CHANNELS

选择一个频道，进入千禧年的未来想象。

02 / CITY ON PAUSE

城市暂停键

让一个不可能出现的柔软物体进入城市空间，借尺度和材质的反差，使日常短暂停顿。

03 / TYPOGRAPHY + SOUND

看得见的声音

以静音、放大与回声三个状态，探索文字的尺度、留白和重复怎样传达听觉节奏。

04 / SECOND SKIN

第二层皮肤

把玻璃和金属作为一组对照：透明与不透明、脆弱与坚硬，改变人像的质感和气质。

05 / SURREAL EVERYDAY

日常出逃

从地铁窗外的海洋出发，让重力、空间、植物与时间依次偏离日常。五张写实超现实摄影作品，共享深青蓝与暖金色的光。
