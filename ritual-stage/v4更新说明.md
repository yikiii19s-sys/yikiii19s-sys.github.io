# SSD UNIT · Ritual Stage / v4

本版在 v3 的本地 WebGL 舞台上迭代，保留五频 IP、镜头预设、自由视角、灯光与原版 19.2 秒循环音轨。

## 本次改动

- Opening：暗场开场，居中祭典片名，只保留 ENTER THE RITUAL。
- Main Stage：默认沉浸观看，隐藏导演台、镜头工具、舞台信息及页脚；保留章节、声音、五幕图腾与导演入口。
- ACT I–V：选择人物会改变灯光和章节，镜头平滑聚焦，唤醒状态累计。支持键盘 1–5。
- 2.5D 影像装置：移除金属矩形画框；在着色器中裁切原图、柔化透明边缘并弱化暗背景，配独立频率光环。未制作独立抠图素材，也未替换为三维人物。
- Director Mode：主动展开后可操作 LIGHT / CAMERA / ENERGY / FX、音量与镜头工具。
- Finale：五频全部唤醒自动触发，亦可点击合奏入口自动唤醒。约 12 秒：暗场 → 五频依次亮起 → 神树层级点亮 → 太阳轮启动 → 金色融合 → 结束标题与镜头拉远。取消群像背景切换，沿用同一套单人素材。
- Archive：演出后出现项目档案入口，介绍五频 IP 和视觉系统。

## 使用

完整解压后，用 Chrome 或 Edge 打开 index.html，无需安装或联网。点击进入解锁声音；右上可静音。拖动舞台旋转与俯仰，滚轮或双指缩放，R 复位。1–5 选择章节；H 隐藏/恢复界面；Escape 关闭档案、跳过演出或关闭导演台，普通观看时返回入口。演出后可重演或重新选择单幕。

系统启用减少动态效果时会跳过 Finale 动画，直接到达完成状态。

## 当前边界

角色仍为 2.5D 概念影像；原图文字可能在部分角色裁切区域留有少量痕迹。音轨仍为原版单一循环，未实现五个独立声部或角色骨骼动画。原《沉浸交互设计.md》保留作为下一阶段设计参考；已实现范围以本文件为准。
