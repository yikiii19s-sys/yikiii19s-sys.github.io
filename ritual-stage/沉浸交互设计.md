# SSD UNIT · 神启舞台：沉浸式体验设计

## 方向

观众进入古蜀未来祭典，亲手唤醒五种频率，五位表演者共同完成一段演出。以青铜、神树、金面与角色服装为主视觉，保留空间亮部和材质细节。界面以场景热点为主，导演台按需展开。

## 当前交付与未完成项

本次本地版修复了舞台画布不接收鼠标事件的错误。支持水平旋转、垂直俯仰、滚轮连续缩放、双指缩放、方向键控制、R 复位、点击角色后镜头偏向角色，以及 H 隐藏界面。声音沿用内置的 19.2 秒合成音轨。

人物目前仍是三维空间中的二维屏幕。本次未将其宣称为三维人物；下面的角色动作、空间音频与五声部混音属于下一阶段设计，尚未实现。

## 一次约 90 秒的体验

1. 进入（约 0–10 秒）：点击进入解锁声音。镜头从入口移向舞台，远处低频逐渐清晰，神树中轴先点亮。到达观众区后交还视角控制，所有镜头动画可跳过。
2. 唤醒（约 10–45 秒）：五个角色处于待机动作。观众靠近或点击角色，镜头平滑聚焦；第一次触发加入该角色声部，第二次触发进入角色近景。未选角色仍保持呼吸、重心移动等动作。
3. 共创（约 45–70 秒）：观众通过一个简单动作影响该角色声部和舞台视觉。变化保持同步，操作可撤回，也可一键自动唤醒，避免把观演变成强制闯关。
4. 合奏（约 70–90 秒）：五声部齐备后，神树完整点亮，五人共同表演约 15–20 秒。观众可切换观众席、侧台和高位机位，也可保持自己拖动的视角。

## 五频交互对应

| 角色 | 场景动作 | 声音与画面反馈 |
| --- | --- | --- |
| 金 / GUIDE | 点击面具，跟随两次简短节拍 | 节奏声部进入；面具边缘亮起，角色转头并完成招手动作 |
| 森 / SAMPLE | 沿神树枝条拖动光点 | 环境声层与旋律依次进入；能量沿枝条上行，角色抬手引导 |
| YAO / DECODE | 拖动角色前方的唱盘 | 改变专属音色与粒子流向；角色手臂随控制反馈 |
| 玉 / BREAK | 点击玉戈热点触发一个节奏重音 | 短促光波扩散；角色完成一步踏拍或挥动动作 |
| 阳 / SYNTHESIZE | 五声部齐备后转动太阳轮 | 调整总体能量，开启五人合奏与舞台升光 |

初版可以全部保留点击替代，拖动与节奏准确率不设硬门槛。

## 让角色真正成为三维人物

先以金 / JIN 制作一个可验证的完整角色，再扩展到五人。以用户的五频角色板为主要造型参考；不同版本的 Q 版与高细节造型不能无说明地混用。

需要：完整三维网格、正背面材质、可动骨骼，以及 idle / greet / perform 三段动作。推荐以 GLB 交接，把材质和动画一起打包。只有一个静态 GLB 可以实现绕看，但不会自动跳舞；只有图片或旋转视频不能替代模型。

角色验收：转到侧面和背面仍有完整体积；灯光真实改变材质；手臂和腿部独立运动；服装和配饰无明显穿插；五人同台在目标电脑上仍能流畅操作。先以一个角色验证这些条件。

已发现 fal 插件有 3D 生成能力，但尚未连接，也尚未验证其可用模型、骨骼或动画能力。连接后先检查实际支持范围，再尝试单角色生成。生成结果需要清理和动作验证，不能预先承诺完全还原 IP。

## 沉浸细节

- 相机：观众席为默认自由视角；角色选择触发可中断的聚焦，用户一拖动立即取回控制权。限制穿地和穿入模型。
- 音频：五个独立声部共用一个节拍时钟；激活角色加入对应声部，靠近角色提高其声部清晰度并改变左右声像。所有声部支持静音。
- 光线：面具、神树和太阳轮拥有不同亮起过程；合奏以升光和连续扫光形成高潮，避免强闪烁。
- 界面：常态仅保留声音和退出；靠近可交互物体时才出现提示。手动控制台放在“导演模式”。
- 可访问性：鼠标拖动、触屏拖动和键盘都能完成基本流程；提供减少动态效果和自动完成唤醒；不依赖仅有声音的指令。

## 实施顺序

A. 修复基础输入与相机（本次完成）。
B. 制作金 / JIN 的三维模型，检查材质、骨骼和动作（待模型资产）。
C. 做金的一个完整互动：走近 → 角色看向观众 → 点击面具 → 加入鼓点 → 角色表演。
D. 验证单角色体验后复制到另外四人，再加入五声部合奏与场景变化。

最终品质的关键是可用的三维角色和动作资产。先把一个角色做对，比同时堆五个未完成模型更有利于判断视觉方向。
