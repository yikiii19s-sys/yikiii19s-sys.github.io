01 / SCRIPT + PROMPT

把镜头意图，写成具体约束。

脚本从运镜效果切入，提示词进一步描述机位、运动路径、人物动作与构图。对人物站位、脸型和景别的限制，也在文字中明确。

02 / CHARACTER REFERENCES

先明确角色，再组织多人场景。

三组角色设定图记录服装、面部角度与表情，为后续场景生成提供参考。

03 / SCENE REFERENCES

不同镜头，对应不同的画面准备。

环绕：先确定人物关系。

四人错落站位，以中心人物为视觉重点。提示词控制人物一致性，并规划前景遮挡、环绕路径和最终定格。

以上为用户提供的制作过程与静态参考图；动态效果以实际成片为准。
